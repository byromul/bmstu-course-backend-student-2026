# CAP04 — красно-зелёное правило выбора

Капсула связывает P02 с автономным действием лекции. Исходное состояние содержит два создаваемых файла: незавершённую `choice.py` и полный открытый `test_choice.py`. Проверка сначала наблюдает ожидаемый `NotImplementedError`, затем заменяет только реализацию проверенным зелёным вариантом и получает два успешных теста.

Среда: Python 3.14.7 и стандартная библиотека. Полная проверка из каталога CAP04:

```text
python check.py
```

Временный каталог, кэш импорта и оба запуска удаляются автоматически. Файлы капсулы не копируются в `console-quest`: домашняя работа отдельно начинает продукт с пустого каталога.
