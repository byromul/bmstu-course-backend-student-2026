# CAP02 — базовые конструкции Python

Капсула связывает K01 с одним полным примером: значения `str`, `int`, `float`, `bool` и `None`, список, словарь, функция, позиционные и именованные аргументы, преобразование строки, условие, `ValueError`, индекс и `return`.

Среда: Python 3.14.7 и стандартная библиотека. Команда запуска из каталога CAP02:

```text
python basics.py
```

Ожидаемый вывод хранится в `expected.txt`. `python check.py` копирует исполняемый файл в новый временный каталог, запускает его, сравнивает стандартный вывод, проверяет пустой stderr и удаляет временные данные.
