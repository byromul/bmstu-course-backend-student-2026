# Автономные капсулы лекции 1

Каталог содержит четыре независимых примера:

- `CAP01` — два экземпляра с независимым состоянием;
- `CAP02` — значения, коллекции, функция и проверяемое правило выбора;
- `CAP03` — два модуля, импорт, класс, метод, `@dataclass` и простой декоратор;
- `CAP04` — красно-зелёный переход от `NotImplementedError` к двум успешным тестам.

Все капсулы используют Python 3.14.7 и только стандартную библиотеку. Общая команда из этого каталога:

```text
python check_all.py
```

Каждый `check.py` создаёт собственный временный каталог и удаляет его после проверки. Ни одна капсула не читает и не изменяет `console-quest`.
