# EX03 — объектная модель и два модуля

Задача связывает K19 с полным многомодульным примером. `scene.py` объявляет класс, атрибут класса, атрибуты экземпляра и метод через готовый `@dataclass`; `use_scene.py` импортирует класс, читает применение простого декоратора без параметров и вызывает метод.

Среда: Python 3.14.7 и стандартная библиотека. Команда запуска из каталога EX03:

```text
python use_scene.py
```

`python check.py` копирует оба модуля в новый временный каталог, запускает точку входа, сверяет `expected.txt` и удаляет временные данные.
