# EX04 — красно-зелёное правило выбора

Задача возвращается к правилу выбора сцены из P02 и показывает устройство теста перед разбором AAA. Исходное состояние содержит два создаваемых файла: незавершённую `choice.py` и полный открытый `test_choice.py`. Проверка сначала наблюдает ожидаемый `NotImplementedError`, затем заменяет только реализацию проверенным зелёным вариантом и получает два успешных теста.

Среда: Python 3.14.7 и стандартная библиотека. Полная проверка из каталога EX04:

```text
python check.py
```

Временный каталог, кэш импорта и оба запуска удаляются автоматически. Файлы задачи не копируются в `console-quest`: домашняя работа отдельно начинает проект с нуля.
