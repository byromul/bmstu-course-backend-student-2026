# Автономные задачи лекции 1

Каталог содержит три независимых примера:

- `EX01` — два экземпляра с независимым состоянием;
- `EX02` — значения, коллекции, функция и проверяемое правило выбора;
- `EX03` — два модуля, импорт, класс, метод, `@dataclass` и простой декоратор.

Все задачи используют Python 3.14.7 и только стандартную библиотеку. Из этого каталога задачи проверяются отдельно:

```text
python L01-EX01/check.py
python L01-EX02/check.py
python L01-EX03/check.py
```

Каждый `check.py` создаёт собственный временный каталог и удаляет его после проверки. Ни одна задача не читает и не изменяет `console-quest`.
