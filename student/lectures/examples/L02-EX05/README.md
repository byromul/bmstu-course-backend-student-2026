# EX05 — один тест с тремя наборами данных

Из корня выданного пакета активируйте окружение L02 с `pytest` и выполните `python -B student/lectures/examples/L02-EX05/check.py`. Проверка собирает три отдельных сценария из одной функции `test_choice` и запускает их в новом временном каталоге.

Для самостоятельной пробы откройте `test_choice.py`, замените ожидаемое значение второго сценария с `LOSS` на `WIN` и выполните `python -B -m pytest -q -p no:cacheprovider test_choice.py` из каталога EX05. Убедитесь, что падает только сценарий `second`, затем восстановите `LOSS` и повторите проверку. Файлы `console-quest` задача не читает.
