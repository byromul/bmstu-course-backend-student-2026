# Внешняя проверка этапов двух продуктов

Каталог содержит открытое проверяющее средство `ART17`. Оно принимает каталог продукта только для чтения, создаёт рабочее зеркало во временном каталоге, выполняет проверки в зеркале и записывает отчёт за пределами продукта.

## Запуск

```text
python check.py \
  --product console-quest \
  --stage HW01 \
  --project-dir ../console-quest \
  --report ../reports/HW01.json
```

Допустимые сочетания:

- `console-quest` и `HW01`–`HW04`;
- `django-quest` и `HW05`–`HW08`.

Код завершения `0` означает успешную проверку, `1` — расхождение продукта с контрактом этапа, `2` — ошибку вызова или среды. Проверка позднего этапа включает обязательные файлы и команды предыдущих этапов того же продукта. На HW01 средство также подтверждает наличие локального Git-репозитория и в отдельных процессах проходит положительный и отрицательный финалы и восстановление после неверного ввода.

Отчёт содержит выполненные проверки, команды, коды завершения, безопасный ограниченный вывод и первое расхождение. Средство скрывает значения токенов и секретных ключей, но студент всё равно не должен передавать настоящие секреты в командной строке или сохранять их в проекте.

## Самопроверка средства

```text
python -m unittest discover -s tests -v
```

Эта команда проверяет интерфейс и безопасную обработку ошибочного продукта. Она не заменяет проверку конкретной домашней работы.
