# Конспект лекции 3 — HTTP, логи и Compose

Материал дополняет слайды L03. HW03 продолжает `console-quest` от тега `hw02-ready` и создаёт клиент и сервер без Django.

## Два процесса

Клиент и сервер имеют разную память. Клиент отправляет HTTP-запрос, сервер выбирает обработчик и возвращает статус с JSON. Состояние партии остаётся у клиента.

URL содержит схему, узел, порт, путь и необязательную строку запроса. Запрос содержит метод, путь, параметры, заголовки и необязательное тело. Ответ содержит статус, заголовки и представление.

## Четыре операции

- `POST /api/v1/characters/initialize` возвращает начальное состояние;
- `GET /api/v1/scenes/{scene_id}` возвращает сцену;
- `POST /api/v1/dice/rolls` возвращает бросок 1–6;
- `POST /api/v1/combat/attacks/resolve` рассчитывает один удар.

Операция удара получает состояния участников и два броска. Она не читает и не сохраняет скрытую партию.

## Чистое предметное правило

Чистая функция определяется аргументами и не изменяет внешнее состояние. HTTP-слой разбирает JSON и выбирает статус, а функция боя проверяет значения и возвращает новое состояние защитника.

## Слои диагностики

Проверяйте по порядку:

1. Клиент и URL;
2. соединение и HTTP;
3. маршрут и обработчик;
4. предметную функцию;
5. источник данных.

На каждом шаге формулируйте одну гипотезу и одно наблюдение. Лог связывает запрос и ответ по `request_id`, методу, пути и статусу; тело и секреты не копируются.

## SSH

SSH-клиент подключается к серверу по адресу, пользователю и порту. Открытый ключ размещается на сервере, закрытый остаётся у владельца. До доверия проверяется отпечаток сервера.

## Контейнеры и Compose

Образ — шаблон, контейнер — запущенный изолированный процесс, Dockerfile — инструкция сборки, сервис Compose — конфигурация процесса, именованный том — отдельное хранилище.

Внутри контейнера клиента `localhost` означает сам клиентский контейнер. Имя `server` разрешается во внутренний адрес серверного сервиса, поэтому клиент использует `http://server:8000`.

Обычный `down` удаляет контейнеры и сеть, но сохраняет именованный том. `down -v` дополнительно удаляет данные тома.

## Автономные капсулы

```bash
python student/lectures/capsules/L03/check_all.py
```

CAP01 проверяет четыре loopback-операции, CAP02 — чистый удар, CAP03 — структуру Compose. Если учебная среда запрещает локальный порт, CAP01 запускается в разрешённой локальной среде, а ограничение фиксируется отдельно.

## Самопроверка

Клиент из контейнера обращается к `server`, потому что это имя другого сервиса в сети Compose. `localhost` внутри контейнера клиента указывает на клиент, а не на сервер.
