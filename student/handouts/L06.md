# Конспект лекции 6 — ORM, миграции и административная панель

Материал дополняет слайды L06 и готовит HW06.

## ORM и реляционная база

ORM сопоставляет класс модели с таблицей, поле со столбцом, экземпляр со строкой. Внешние ключи и ограничения продолжают действовать внутри SQLite.

Один Scenario содержит много Scene, одна Scene — много Choice, боевая сцена — не более одного BattleAction. `related_name` задаёт обратный путь.

## `on_delete` и ограничения

`CASCADE` удаляет зависимые строки, `PROTECT` отклоняет удаление используемого объекта, `SET_NULL` сохраняет зависимую строку без связи. Выбор следует предметному смыслу.

Уникальность идентификатора сцены внутри сценария и позиции варианта внутри сцены задаётся ограничениями базы и подтверждается негативными тестами.

## Миграции

```bash
python manage.py makemigrations game
python manage.py migrate --plan
python manage.py sqlmigrate game 0001
python manage.py migrate
python manage.py showmigrations game
```

`makemigrations` создаёт файл инструкции, но не обязана менять рабочую базу. `migrate` применяет неприменённые инструкции и записывает историю в базу.

Сначала прогнозируйте операции, затем читайте файл и SQL, только потом применяйте.

## ORM-запросы

`create` создаёт и сохраняет объект. `filter` возвращает QuerySet с нулём или несколькими строками. `get` ожидает ровно одну строку и сообщает ошибку при другом количестве.

Явная сортировка нужна, если порядок является частью результата.

## Импорт и воспроизводимость

Команда импорта полностью проверяет YAML, затем в одной транзакции создаёт или обновляет связанные записи. Повторный запуск не создаёт дубликаты, ошибка откатывает изменение.

SQLite первого продукта не копируется. База `django-quest` воспроизводится из миграций и открытого `data/scenario.yaml`.

## Административная панель

Регистрация модели, `list_display` и `search_fields` позволяют наблюдать данные уполномоченному локальному пользователю. Панель не заменяет импорт, тесты и API.

Пароль суперпользователя не попадает в Git, YAML или журнал.

## Автономная капсула

```bash
python student/lectures/capsules/L06/check_all.py
```

Капсула создаёт отдельную SQLite-базу в памяти, сохраняет связь и проверяет отклонение дубликата START.

## Самопроверка

`makemigrations` создаёт файл миграции на основе изменения моделей. `migrate` изменяет подключённую базу согласно готовым файлам. Первая команда не заменяет вторую.
