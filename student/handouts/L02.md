# Конспект лекции 2 — данные, тесты и безопасное сохранение

Материал дополняет слайды L02. Практика выполняется в автономных капсулах, а HW02 начинается только от принятого `hw01-ready`.

## JSON, YAML и Python

Объект соответствует словарю, массив — списку, `null` — `None`. В YAML отступы задают вложенность, а кавычки могут менять тип: `hp: 10` — целое число, `hp: "10"` — строка.

Успешный разбор доказывает только синтаксис. Приложение отдельно проверяет версию, обязательные поля, точные типы, диапазоны и существование сцены.

## Сценарий и состояние партии

Сценарий содержит мир и переходы. Сохранение содержит только изменяемую партию:

```yaml
schema_version: 1
current_scene_id: SCN007
player:
  name: Мира
  hp: 6
  str: 3
  def: 2
```

В сохранение не входят весь сценарий, пароль и Bearer-токен.

## Безопасная загрузка

Порядок загрузки:

1. Прочитать текст во временную переменную;
2. разобрать YAML;
3. проверить версию;
4. проверить поля и типы;
5. проверить ссылку на сцену;
6. создать новое состояние;
7. присвоить его только после успеха.

Повреждённый файл не должен частично менять текущую партию.

## Атомарная запись

Сначала создаётся временный файл рядом с целевым. После успешной записи и закрытия `os.replace` заменяет целевой путь. Ошибка до замены оставляет прежнее сохранение рабочим.

## AAA и TDD

AAA делит тест на Arrange, Act и Assert. Красный этап должен дойти до ещё не реализованной границы, зелёный — подтвердить минимальное поведение. Рефакторинг выполняется после зелёного результата с повтором тех же тестов.

Выполните:

```bash
python student/lectures/capsules/L02/check_all.py
```

CAP01 показывает отказ без изменения партии, CAP02 — красно-зелёный AAA-цикл, CAP03 — диагностический и успешный Ruff.

## Трассировка и лог

Трассировку читайте снизу: тип и сообщение исключения, ближайшая строка собственного кода, одна проверяемая гипотеза. Ожидаемые ошибки сохранения превращаются в контролируемый `SaveGameError`; неожиданный дефект сохраняет трассировку.

Лог может содержать операцию, безопасное имя файла, код причины и идентификатор сцены после успеха. Полный YAML и секреты не журналируются.

## Ruff

Линтер проверяет статические правила, форматтер меняет механическое оформление. После автоматической правки нужно прочитать diff, повторить Ruff и запустить тесты. Зелёный Ruff не доказывает правильность поведения.

## Самопроверка

Файл содержит `schema_version: 2` и `hp: "10"`; текущая партия — `SCN007`, `hp = 6`. Правильный прогноз: загрузка отклоняется до изменения, поэтому оба значения до и после совпадают.

## Переход к HW02

HW02 явно создаёт зависимости, Ruff, JSON Schema, `client/storage.py` и `client/tests/test_storage.py`. Студент реализует атомарную запись и безопасную загрузку, сохраняет красно-зелёный результат, проходит регрессию HW01, внешний запуск HW02 и создаёт тег `hw02-ready`.
