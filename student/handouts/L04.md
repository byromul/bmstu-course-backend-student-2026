# Конспект лекции 4 — SQLite и OpenAPI

Материал дополняет слайды L04 и готовит завершение `console-quest` на HW04.

## Реляционная модель

Таблица содержит строки с одинаковыми столбцами. Первичный ключ определяет строку, внешний ключ связывает её с другой строкой. Сценарий связан со многими сценами, сцена — с вариантами, боевая сцена — с одним боевым действием.

`NOT NULL`, `UNIQUE` и внешние ключи защищают данные внутри базы. Значения в SQL передаются параметрами, а не склеиваются со строкой запроса.

## SQLite и воспроизводимость

SQLite хранит локальную базу в одном файле и не требует отдельного серверного процесса. Сам файл не является источником продукта: база воспроизводится из схемы, миграции или команды создания и версионируемого YAML.

Идемпотентный импорт при повторе оставляет тот же результат. Транзакция гарантирует, что ошибка не сохраняет половину графа.

## Контракт API

Четыре операции и стабильные ошибки описываются независимо от реализации. Сервер может перейти от YAML к SQLite, пока метод, путь, поля и статусы остаются согласованными.

`error.code` предназначен для программного ветвления, `error.message` — для человека.

## OpenAPI 3.1

OpenAPI — машиночитаемый контракт в YAML или JSON. Основные части:

- `info` описывает документ;
- `paths` содержит маршруты;
- операция задаётся HTTP-методом;
- `parameters` описывает параметры;
- `requestBody` — тело запроса;
- `responses` — ответы;
- `components` — переиспользуемые схемы.

## Три разных свидетельства

Код `0` валидатора относится к структуре документа. Контрактные тесты сравнивают фактические ответы с ожиданиями. Swagger UI позволяет вручную выполнить один запрос к запущенному серверу.

Ни одно свидетельство не заменяет два других.

## Обзор безопасности

Аутентификация устанавливает пользователя, авторизация проверяет действие, владение связывает пользователя с объектом. Bearer — способ передачи токена; непрозрачный токен и JWT — разные форматы.

OAuth 2.0 относится к делегированию доступа, OpenID Connect — к идентификации поверх него. Bearer требует TLS в реальной сети; локальный HTTP курса используется только для разработки.

## Самопроверка

Валидатор с кодом `0` доказывает структурную валидность прочитанного OpenAPI. Успешный GET в Swagger UI доказывает только один фактический запрос. Одно наблюдение не покрывает границу другого.
