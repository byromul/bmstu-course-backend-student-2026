## Зафиксируйте контракт состояния

YAML-снимок содержит ровно следующие значения:

```yaml
schema_version: 1
current_scene_id: SCN007
player:
  name: Мира
  hp: 6
  str: 3
  def: 2
```

Все поля обязательны; дополнительные поля запрещены. `schema_version` равна `1`; идентификатор и имя — непустые строки; характеристики — целые неотрицательные числа. Логические значения не принимаются как числа. Токен, текст сцен и весь сценарий не сохраняются.

## Объявите самостоятельную границу

В `client/storage.py` самостоятельно реализуйте:

- `SaveGameError` для контролируемого отказа чтения или проверки;
- `save_game(path, state) -> None` для атомарной записи;
- `load_game(path, scene_exists) -> GameState` для полной проверки и возврата нового состояния.

`scene_exists` получает идентификатор сцены и возвращает логическое значение. `load_game` не изменяет переданный текущий объект: вызывающий код присваивает результат только после полного успеха.

## Начните с красного AAA-теста

В `client/tests/test_storage.py` создайте `StorageTests.test_round_trip`. Arrange готовит состояние и `TemporaryDirectory`, Act сохраняет и загружает его, Assert сравнивает сцену и все характеристики.

До реализации запустите:

```bash
python -m unittest client.tests.test_storage.StorageTests.test_round_trip -v
```

Правильный красный результат доходит до `NotImplementedError` или отсутствующего поведения публичной функции. Ошибка импорта или синтаксиса не считается красным свидетельством.

## Реализуйте атомарную запись

Самостоятельный алгоритм `save_game`:

1. Преобразует состояние в новую структуру и проверяет её;
2. создаёт каталог назначения;
3. записывает YAML во временный файл рядом с целевым;
4. закрывает файл;
5. заменяет целевой путь через `os.replace`.

Используйте `yaml.safe_dump` с читаемым русским текстом. Сбой до замены не должен обрезать прежнее сохранение.

## Реализуйте безопасную загрузку

Самостоятельный алгоритм `load_game`:

1. Читает текст во временную переменную;
2. разбирает его через `yaml.safe_load`;
3. проверяет JSON Schema;
4. отдельно отклоняет `bool` вместо целого числа;
5. проверяет `current_scene_id` через `scene_exists`;
6. создаёт и возвращает новый `GameState`.

Отсутствующий файл, повреждённый YAML, версия `2`, лишнее или пропущенное поле, строка вместо `hp`, отрицательное число и неизвестная сцена дают `SaveGameError`. Сообщение называет причину, но не печатает полное содержимое.

## Добавьте негативные AAA-тесты

Отдельными тестами подтвердите:

- отсутствующий файл;
- синтаксически повреждённый YAML;
- несовместимую версию;
- ошибочный тип и отрицательную характеристику;
- неизвестную сцену;
- неизменность текущих `current_scene_id = SCN007` и `hp = 6` после отказа.

Хотя бы один тест проверяет `WARNING` без полного YAML в сообщении. Все временные сохранения создаются вне рабочего дерева.

## Подключите явные команды клиента

В `client/__main__.py` распознавайте `save` и `load` между сценами. Успех печатает `Игра сохранена` или `Игра загружена`; контролируемый отказ — `Загрузка отклонена: <причина>` и оставляет прежнюю партию.

Автоматическое сохранение при переходе, финале или ошибке не добавляйте.

## Критерии готовности

Статус «готово» ставится, если одновременно:

- входом был чистый `hw01-ready`;
- точное дерево HW02 создано явными действиями;
- сохранение содержит полный контракт версии `1` и записывается атомарно;
- ошибочные данные отклоняются до изменения партии;
- сохранён красно-зелёный AAA-переход;
- тесты HW01 и HW02 и Ruff проходят;
- внешняя проверка завершилась кодом `0`;
- рабочее дерево чистое и создан тег `hw02-ready`.

Если критерий не выполнен, работа получает формирующий статус «нужно продолжение» и одно конкретное следующее действие.
