# Серверная разработка на Python и Django: от основ до JSON API

Этот каталог содержит только материалы, предназначенные студентам.

## Результат курса

После курса студент из двух пустых каталогов создаёт и тестирует два независимо запускаемых продукта: клиент-серверный квест на Python без веб-фреймворка и серверный квест на Django 5.2 LTS с ORM, миграциями, JSON API и Bearer-аутентификацией.
