# Каталог терминов курса и карта их раскрытия

Каталог фиксирует канонические названия и показывает, где термин впервые вводится и где раскрывается или применяется дальше. Он не заменяет определение в лекции или задании: каждый самостоятельно читаемый материал объясняет новый термин при первом содержательном употреблении.

Названия лекций ниже соответствуют точкам раскрытия по `delivery-plan.yaml`; формулировки согласованы с текущими исходниками лекций 1–8. При изменении материала запись каталога обновляется вместе с лекцией без смены смысла модели курса.

Столбец «Русская форма» задаёт название для русскоязычного текста курса. Идентификаторы, команды, аббревиатуры и названия продуктов сохраняют исходное написание. Столбец «Английская форма» фиксирует одно соответствие для чтения документации и не разрешает произвольно заменять русское название в основном тексте. Последний столбец ограничивает область употребления термина.

## Лекция 1 — запуск, Python, структура программы и Git

### Применяемые сейчас понятия

На занятии каждое новое понятие вводится отдельно: один термин получает одно каноническое название, самостоятельное определение и собственный визуальный блок. Связи между понятиями показываются только после того, как каждое из них уже можно узнать по отдельности.

### Справочные и уже знакомые понятия

`Стандартный ввод`, `None`, общее понятие исключения, `__init__.py`, зафиксированная версия, обратная совместимость, `self` и флаг `--ff-only` нужны для точного чтения примеров. Их определение остаётся в конспекте и таблице ниже, а подробность закрепляется при первом действии. Переменная, список, словарь, ветвление, цикл, функция и возвращаемое значение входят в проверяемое входное требование курса; на лекции 1 студент сопоставляет уже знакомый смысл с синтаксисом Python, а не изучает эти понятия с нуля.
