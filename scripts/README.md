# Независимая предварительная проверка среды

`preflight.py` проверяет среду до создания `console-quest` и `django-quest`. Сценарий не читает файлы продукта и не требует клонированного репозитория, активированного окружения или установленных пакетов курса.

Базовый профиль выполняет следующие действия:

- проверяет точную версию Python 3.14.7;
- создаёт отдельное временное виртуальное окружение и проверяет запись UTF-8;
- проверяет Git, `user.name` и `user.email`;
- создаёт во временном каталоге новый Git-репозиторий, файл и коммит;
- удаляет временные данные после завершения.

Запуск из корня комплекта курса:

```text
python scripts/preflight.py
```

Перед лекцией 3 студент отдельно загружает проверочный образ выбранным Podman или Docker и запускает контейнерный профиль:

```text
python scripts/preflight.py --profile containers
```

Код завершения `0` означает готовность проверенной части среды, `1` — первое наблюдаемое несоответствие, `2` — ошибку параметров командной строки. Проверка редактора, доступа к материалам, SSH и письменным каналам остаётся ручной, потому что сценарий не может честно подтвердить действия пользователя или внешние доступы.

Самопроверка сценария:

```text
python -m unittest discover -s scripts/tests -v
```
